# 404 Page Template Specification

**Template Type:** Theme Builder > Error 404
**Conditions:** 404 Page
**Class Hook:** `gc-404-page-v1`

---

## Overview

The 404 page provides a friendly, branded experience when visitors land on a non-existent page. It features a prominent back button with JavaScript history fallback (non-negotiable requirement), helpful navigation links, and a search function.

---

## Non-Negotiable Requirements

1. **Back Button with JS History Fallback** — The back button must use `history.back()` with a fallback to homepage if there's no history
2. **Match Site Theme** — Design must be consistent with the Grander brand
3. **Multiple Recovery Paths** — Provide search, quick links, and contact options

## Back Button JavaScript (Critical)

**This is a non-negotiable requirement.** The back button must:
1. Use `history.back()` when there is browser history
2. Fall back to homepage if there's no history or direct URL visit

### JavaScript Implementation

Add to `grander-core.js` or footer:

```javascript
// 404 Back Button Handler
document.addEventListener('DOMContentLoaded', function() {
    var backButton = document.getElementById('gc-back-button');

    if (backButton) {
        backButton.addEventListener('click', function(e) {
            e.preventDefault();

            // Check if there's history to go back to
            if (window.history.length > 1 && document.referrer !== '') {
                // There's history and a referrer, go back
                window.history.back();
            } else {
                // No history or direct visit, go to homepage
                window.location.href = '/';
            }
        });
    }
});
```

### Alternative Inline Approach

If external JS is not possible:

```html
<a href="/"
   id="gc-back-button"
   onclick="if(history.length > 1 && document.referrer) { history.back(); return false; }"
   class="gc-btn gc-btn--brown gc-404-back-btn">
    <svg><!-- Arrow icon --></svg>
    Go Back
</a>
```

## Responsive Behavior

### Desktop (1025px+)
- 404 number: 120px
- Title: 48px
- 4-column quick links grid
- 60vh min hero height

### Tablet (768px - 1024px)
- 404 number: 100px
- Title: 40px
- 2-column quick links grid

### Mobile (767px and below)
- 404 number: 80px, 4px letter-spacing
- Title: 32px
- 1-column quick links (stacked)
- Reduced padding
- Full-width buttons

## Testing the 404 Page

1. **With History:** Navigate to any page, then manually enter a non-existent URL. Click "Go Back" — should return to previous page.

2. **Without History:** Open a new browser tab/window and directly visit a non-existent URL like `/this-does-not-exist/`. Click "Go Back" — should redirect to homepage.

3. **Search:** Enter a search term and verify search results page loads.

4. **Quick Links:** Verify all 4 quick links navigate correctly.
